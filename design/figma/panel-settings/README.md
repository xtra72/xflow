# 그래프 패널 설정 화면 → Figma

Figma 는 `.fig` 를 외부에서 만들 수 없고 REST API 도 문서 내용은 읽기 전용이라, **플러그인으로
Figma 안에서 직접 그린다**. 결과는 이미지가 아니라 프레임·텍스트라 그대로 편집할 수 있다.

## 설치

Figma 데스크톱 → `Plugins` → `Development` → `Import plugin from manifest…` → 이 폴더의
`manifest.json`. 이후 `Plugins` → `Development` → **xflow — 그래프 패널 설정 화면**.

## 두 가지 경로

### 1. 실제 화면 그대로 (권장)

코드를 읽어 손으로 옮긴 구조는 **반드시 실제와 갈라진다.** 조건부 렌더, flex `order`(이 화면은
미리보기가 `order-1`, 옵션 컬럼이 `order-3` 이라 JSX 순서와 좌우가 반대다), 사용자가 끌어 놓은
컬럼 폭까지 코드만 봐서는 알 수 없다. 그래서 그리는 값을 화면에서 직접 읽는다.

1. 패널 설정 화면(`/panels/:id/settings`)을 **보고 싶은 상태 그대로** 연다
2. DevTools 콘솔에 `extract.js` 전체를 붙여 넣고 실행 → `panel-settings-dom.json` 내려받기
3. 플러그인을 열고 그 JSON 을 붙여 넣은 뒤 **붙여 넣은 화면 그리기**

좌표·색·글자 크기·테두리를 화면에서 읽은 값 그대로 옮긴다. 해석하지 않으므로 어긋날 자리가
없다. 아이콘(SVG)만 자리표시자 사각형으로 남긴다 — 벡터까지 옮기면 JSON 이 폭증한다.

### 2. 목업 (구조 스케치)

**목업으로 그리기** 를 누르면 다크·라이트 화면과 디자인 배지 펼침 상태를 Auto Layout 으로
그린다. 실행 중인 앱이 없을 때, 또는 배치를 새로 짜 볼 때 쓴다. 값은 `index.css` 토큰과
`ko.json` 라벨에서 옮겼지만 **구조는 손으로 적은 것이라 실제와 다를 수 있다.**

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 플러그인 정의 |
| `ui.html` | JSON 붙여넣기 창 + 두 버튼 |
| `code.js` | DOM 트리 → 프레임 변환 + 목업 생성 |
| `extract.js` | 브라우저 콘솔용 추출 스크립트 |

## 글꼴

한글 화면이라 Inter 로는 글자가 깨진다. Pretendard → Noto Sans KR → Apple SD Gothic Neo →
Inter → Roboto 순으로 **먼저 로드되는 것**을 쓴다. 셋 다 없으면 그리지 않고 실패를 알린다.

이 폴더는 빌드·테스트에 물려 있지 않다. 지워도 앱에 영향이 없다.
